# Retokenization Invariance in Language Models

This repository contains the code and figure-reproduction notebooks for our work on
retokenization and typo-based variation in large language models. The project studies
how model behavior changes when the same underlying text is presented under different
tokenizations or light character-level perturbations.

## Repository layout

- `eval/`: result loading, pass-curve computation, benchmark utilities, and shared helpers
- `experiments/passat/`: experiment entrypoints for retokenization and typo variants
- `figure_notebooks/`: notebooks used to reproduce the paper figures
- `data/`: local data layout for raw experiment outputs
- `outputs/figures/`: default destination for figures generated by notebooks

## Public-release conventions

- Raw experiment outputs are expected under `data/raw/Tokenizer_passK/` and
  `data/raw/TokenizationProject/`.
- The repo ships only placeholders for those directories. Replace them with your local
  copies of the actual result trees when reproducing figures.
- Experiment scripts default to writing local outputs into those same `data/raw/`
  trees.
- Notebook exports should be written to `outputs/figures/`.

## Setup

Create an environment with the project dependencies you already use for experiments
and notebooks. At minimum, the figure workflow expects:

- `python`
- `pandas`
- `matplotlib`
- `numpy`
- `jupyter`
- model/runtime dependencies already required by the experiment scripts

## Reproducing figures

1. Download or copy the raw result trees into `data/raw/`.
2. Open the notebooks in `figure_notebooks/`.
3. Run the notebook corresponding to the figure you want.
4. Generated figures will be written to `outputs/figures/`.

See [figure_notebooks/README.md](figure_notebooks/README.md)
for the notebook-to-figure mapping.
